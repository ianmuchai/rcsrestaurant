# iPhone Installation Guide

The public `/install-app` route is the QR destination. Download App opens a supported browser's install prompt only after a user clicks. Safari requires its native Share menu and Add to Home Screen flow; the page explains those steps instead of copying or sharing the link automatically.

The image at `public/images/pwa/ios-share-button.png` is Apple's actual 50x60 Share-button image, downloaded without alteration from:

https://ipcdn-web.apple.com/assets/v2/web/42ec2ad1-0cb9-4cba-99e8-c98d297d2349

Instructions and image attribution link to Apple's user guide:

https://support.apple.com/en-lamr/guide/iphone/iphea86e5236/ios
